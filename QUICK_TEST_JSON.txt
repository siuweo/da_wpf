# Thử Camera JSON (cổng 7500, 1 dòng JSON / lần phát hiện)

Toạ độ theo hệ robot: x, y, z (mm, z = mặt trên của vật, Z thực tế), theta (độ).
Tuỳ chọn: "vx", "vy" (mm/s – vận tốc vật nếu camera tự đo), "age_ms" (độ trễ xử lý ảnh).

## Dán vào ô "JSON thử" rồi bấm "Apply Camera JSON (Test)"
{"camera_detect_id":1,"x":150.50,"y":-250.00,"z":40.00,"theta":20.00}
{"camera_detect_id":3,"x":175.00,"y":-225.00,"z":35.50,"theta":60.00}
{"camera_detect_id":99,"x":100.00,"y":-250.00,"z":45.00,"theta":30.00}        <- không khớp IF nào -> nhánh ELSE
{"camera_detect_id":1,"x":150,"y":-300,"z":40,"theta":0,"vy":60,"age_ms":80}  <- vật đang trôi +Y 60 mm/s

## Gửi thật qua socket (Python chạy trên cùng laptop với GUI)
import socket, json
det = {"camera_detect_id": 1, "x": 150.5, "y": -250.0, "z": 40.0, "theta": 20.0}
s = socket.create_connection(("127.0.0.1", 7500))    # có thể giữ kết nối và gửi liên tục
s.sendall((json.dumps(det) + "\n").encode())

Định dạng cũ {"Device":"Camera","ID":1,"x":...,"y":...,"z":...,"theta":...} vẫn được chấp nhận.
GUI chỉ dùng kết quả khi chương trình đang chờ vật (sau khi IPC báo DONE); gửi lúc robot bận sẽ bị bỏ qua.
